# K-iary

K-iary is a modern encrypted diary for Windows.

It is designed for private writing with a clean Windows-native feel, rich text editing, markdown support, and timed journal sections.

## Why K-iary

- Private local vault protected by your master password
- Rich Text and Markdown modes in one app
- Timed Journal syntax for structured, chronological notes
- Auto-save support
- Import and export options
- Windows 11 style UI with transparency effects on supported systems

## Timed Journal Syntax

Start a line with a timestamp to create a timed section automatically:

```text
25/11/2025@10:59pm : Reflection
```

Timed sections show up in the sidebar and can be collapsed or expanded.
